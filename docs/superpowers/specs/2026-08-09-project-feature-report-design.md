# Xiaoda Agent 项目功能总结 HTML 设计

## 目标

生成一份零网络依赖、可直接双击打开的单文件交互式 HTML 报告，系统呈现 Xiaoda Agent 当前源码中的产品能力、后端模块、前端页面、接口、运行链路、工程保障与注意区域。

报告必须以当前磁盘源码为事实来源，完整覆盖生产后端包、根级 Python 模块、Web 路由、前端页面与组件、测试、CI、部署、脚本、配置、诊断、评测和故障注入能力。

## 交付物

- 输出文件：`d:\移动Xiaoda\xiaoda-agent-project-report.html`
- 单文件内嵌 CSS、JavaScript、SVG 和报告数据
- 不引用 CDN、远程字体、远程图片或第三方运行时
- 支持桌面与移动端浏览
- 支持浏览器打印和另存 PDF

## 信息架构

1. 项目总览：定位、版本、技术栈、规模统计和核心特色
2. 系统架构：接入层、编排层、能力层、基础设施层和工程保障层
3. 核心运行链路：启动、初始化、消息处理、模型工具循环、记忆召回和后台任务
4. 产品能力矩阵：聊天、多 Agent、模型、工具、MCP、记忆、知识图谱、情绪、媒体、主动任务、安全和多通道
5. 后端模块百科：全部生产包和根级 Python 模块
6. Web 服务与 API：FastAPI 支撑模块、REST 路由组、WebSocket 协议和认证边界
7. 前端功能：全部页面、组件、状态管理、视觉系统和交互能力
8. 数据与认知：SQLite、FTS、向量、知识图谱、FSRS、Reranker、画像和学习系统
9. 工具与扩展：内置工具、MCP、插件、市场、Skill 和工作流
10. 工程保障：测试、CI、发布、Docker、Kubernetes、脚本、诊断、故障注入和评测
11. 配置与部署：环境变量、运行时配置、Workspace、桌面、Web、CLI、QQ、微信和 ACP
12. 风险与阅读路线：复杂模块、配置真相源、动态注册、并发、文档漂移和推荐阅读顺序

## 视觉设计

- 采用须弥草元素主题：深森林底色、草绿主色、嫩芽绿辅助色、智慧金强调色
- 使用低透明度玻璃面板、叶片轮廓、微光边框和柔和背景光晕
- 首屏采用品牌标题、版本徽标、规模统计和能力标签形成明确层级
- 使用原生 SVG 绘制架构关系和图标，不使用外部图片
- 动效保持自然克制，并尊重 `prefers-reduced-motion`
- 正文优先保证高密度技术内容的可读性，不以装饰牺牲信息获取效率

## 交互设计

- 固定侧边目录与滚动位置高亮
- 全文搜索模块名、文件名、类名、功能和术语
- 按产品、核心、数据、工具、安全、接入、前端和工程分类筛选
- 模块卡片支持单项展开、全部展开和全部折叠
- 搜索结果实时更新命中数量并保留所在章节
- 文件路径支持复制
- 支持深色草元素主题与高对比阅读主题切换
- 支持返回顶部和打印模式
- URL Hash 可定位主要章节

## 数据组织

报告内容以 JavaScript 数据结构内嵌，模块数据至少包含：

- 名称与类别
- 目录或文件路径
- 模块职责
- 关键能力
- 主要依赖
- 入口或调用方
- 代表文件
- 修改注意事项

页面、路由、组件和工具清单使用相同的结构化渲染方式，避免手写重复布局并确保搜索和筛选一致。

## 容错与降级

- JavaScript 禁用时仍显示总览、架构和关键内容
- 搜索和筛选失败不影响正文阅读
- 不支持剪贴板 API 时回退为选择路径文本
- 移动端隐藏固定侧栏并提供目录按钮
- 低性能或减少动态效果模式下关闭环境粒子和位移动画

## 验证标准

- 单文件可在无网络环境直接打开
- HTML、CSS 和 JavaScript 无语法错误
- 浏览器控制台无运行错误
- 桌面和移动视口无横向溢出或遮挡
- 搜索、筛选、折叠、主题切换、目录跳转和路径复制可用
- 所有已盘点模块均能在页面中检索到
- 页面显示当前项目版本和生成日期
- 打印模式隐藏交互控件并保持章节结构清晰

## 范围边界

- 报告描述源码已经实现的能力，不承诺未配置的外部 Provider、微信、QQ、邮箱、MCP 或媒体服务当前可用
- 不修改现有 Xiaoda Agent 运行代码和 Vue WebUI
- 不引入新依赖，不执行生产服务，不写入项目数据库
- 不把历史工作树、构建产物、模型权重或临时调试目录作为独立产品模块重复统计
