# Android G5-01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建五模块 Kotlin Android 工程、三构建变体和提交后产出 APK 的独立 CI。

**Architecture:** `:app` 只负责 Activity 和装配，WebView、安全、Bridge 与终端状态分别由独立 library module 提供。G5-01 只建立可测试安全骨架，不提前引入本地 runtime 或真实凭证。

**Tech Stack:** Kotlin、Android Gradle Plugin、Gradle Kotlin DSL、AndroidX AppCompat/Core/WebKit、JUnit、GitHub Actions
